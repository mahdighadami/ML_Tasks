# ML_Tasks

A structured repository containing end-to-end Machine Learning pipelines, statistical analyses, and automated reporting.

---


## 🛠 Project Breakdown

* **News Popularity:** Regression modeling to predict the virality and reach of online articles.
* **Hypothesis Testing:** Statistical evaluation and distribution analysis to validate feature selection.
* **Amazon Sales:** Trend forecasting and performance analysis, complete with a generated **Amazon report**.
* **Customer Personality:** Unsupervised learning for customer profiling, backed by a **Customer report**.

---

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/mahdighadami/ml_tasks.git
cd ml_tasks

# Install environment dependencies
pip install -r requirements.txt

# Run a specific task
cd workspace/"Amazon sales"
jupyter notebook

```

**Tech Stack:** Python, Pandas, NumPy, Scikit-Learn, SciPy, Matplotlib.
